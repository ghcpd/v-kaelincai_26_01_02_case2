# Final Prompt: Fix Flaky Python Marketing Lottery System

## Role & Objective

You are a senior software engineer tasked with fixing a Python marketing lottery system that exhibits flaky/non-deterministic behavior. Your objective is to:
1. Analyze the existing flaky project structure and understand the bugs
2. Create a fixed version in a new directory that eliminates all sources of non-determinism
3. Ensure all 13 tests pass consistently across multiple runs
4. Perform comprehensive validation to verify the fixes
5. Deliver complete documentation of changes and verification results

**Key Bugs to Fix:**

3. **Non-Deterministic Prize Iteration** - Uses set for prize type iteration with undefined order
4. **Global Random State** - Uses module-level `random` without instance-level seed control

3. **Implement Deterministic Testing Contract**:
