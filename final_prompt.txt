### Phase 4: Implement Deterministic RNG Fix
Apply the following fixes to `lottery.py`:

**Fix 1: Instance-Level RNG with Seed Support**
- Replace module-level `random.random()` calls with instance-level RNG
- Use `self._rng = random.Random(seed)` in `LotterySystem` initialization
- Modify `create_lottery(seed=X)` to pass seed to `LotterySystem(random_seed=seed)`
- When seed is provided: deterministic results (same seed = same output)
- When no seed: production randomness from default initialization
- Impact: Enables deterministic testing while preserving production randomness

**Fix 2: Deterministic Prize Selection Order**
- Replace unordered `set` with ordered list for prize types
- Use deterministic iteration order: `[FIRST, SECOND, THIRD, NONE]`
- Ensures consistent prize selection across multiple runs
- Impact: Eliminates randomness from data structure iteration

**Fix 3: User.ip_address Default and IP Check Logic**
- Change IP default from fixed value to `None`
- Skip IP quota checks when IP is `None` (not specified)
- Prevents artificial rate limiting in tests with many synthetic users
- Impact: Large-sample statistical tests run without artificial constraints

**Fix 4: Prize Pool Immutability During Tests**
- Prevent `draw()` from mutating shared `PrizePool` in statistical tests
- Keep `PrizePool.consume()` available for explicit consumption testing
- Ensures large-sample statistical tests reflect intended probabilities
- Impact: Statistical assertions pass with correct probability distributions
